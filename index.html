Programmatic Alpha & Execution Endpoints

Designed for programmatic quant systems, automated MT5 execution daemons, and low-latency trading engines.

GET /v1/signals/latest

Stream real-time directional forecasts filtered by high-conviction dead-zones (P ≥ 0.62), expected edge in basis points, and volatility-adjusted risk allocations across 123 currency pairs.

Parameters: threshold (0.50–0.80), timeframe (M15, H1, D1), instruments
GET /v1/regimes/embeddings

Retrieve 32-dimensional latent market regime embeddings from our 480-bar causal Temporal Convolutional Network autoencoder. Ideal for regime-conditional sizing and portfolio stress tests.

Returns: 32-D normalized vector, cluster attribution, volatility regime index
GET /v1/risk/covariance

Dynamic rolling cross-pair covariance and correlation matrices calculated point-in-time across all major, minor, and exotic currency pairs to eliminate concentration risk and compute risk parity.

Formats: JSON dense matrix, compressed Parquet, or sparse pairwise correlation
POST /v1/execution/webhook

Sub-second automated order routing webhook. Dispatches split tickets (TP1 + runner) with automated 8-hour horizon timeout exits directly to our headless Linux MT5 bridge or your private VPS.

Payload: Symbol, units, slippage tolerance, stop loss ATR multiplier, horizon hours

Documentation & FAQ

Frequently Asked Questions

Everything you need to know about integrating the Voltacent Alpha API into your trading stack.

Can I use this API with prop firms like FTMO and The 5%ers?

Yes. The Voltacent API outputs standard REST and WebSocket signals. Traders can use our lightweight Python bridge or webhook integration to route signals directly into MetaTrader 5 (MT5) on prop firms that permit algorithmic EAs, such as FTMO, The 5%ers, and Funding Pips.

What execution latency should I expect from the endpoints?

Our primary execution API cluster is hosted in AWS us-east-1 (N. Virginia). Expected REST round-trip latency is 25–45ms within North America and sub-10ms via AWS VPC peering. WebSocket streaming broadcasts signals in under 15ms.

How does Voltacent eliminate lookahead bias and data leakage?

Every feature is strictly point-in-time. We implement Marcos López de Prado's purged walk-forward validation with per-instrument trading bar embargoes. Prior to model training, our automated 15.2M-row leakage scanner verifies that zero future information has contaminated features.

Which programming languages and execution platforms are supported?

The REST & WebSocket APIs are language-agnostic and work with any HTTP or WebSocket client. We provide official open-source SDKs and boilerplates for Python, TypeScript/Node.js, C#, and Go, alongside headless MT5 Linux daemons.
